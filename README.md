This repository is a fork of pear/Net_POP3.

The fork contains modifications required by the EmailReporting plugin for MantisBT and is maintained by SL-Gundam.


## Original README
This package is http://pear.php.net/package/Net_POP3 and has been migrated from http://svn.php.net/repository/pear/packages/Net_POP3

Please report all new issues via the PEAR bug tracker.

If this package is marked as unmaintained and you have fixes, please submit your pull requests and start discussion on the pear-qa mailing list.

To test, run either
$ phpunit tests/
  or
$ pear run-tests -r

To build, simply
$ pear package

To install from scratch
$ pear install package.xml

To upgrade
$ pear upgrade -f package.xml
